# 大世界美术风格参考 — 泰拉瑞亚（Terraria）

> 来源: 海钺 2026-08-24 提供 · 用于 WorldScene 像素风升级

泰拉瑞亚视觉风格一句话概括：**复古像素 × 多层奇幻生态 × 昼夜动态氛围**。

## 🎨 核心特征

### 🔲 2D 侧视像素风
- 经典 16 位像素美术：分辨率低但信息密度极高
- 每个方块/敌怪/装备靠有限像素点表达，细节却丰富（盔甲独立动态帧、BOSS 特效、水下光线折射）
- 「看着简陋，动起来惊艳」的反差是核心魅力

### 🌈 多群系色彩体系
按垂直分层 + 水平生态划分，每区域有高度辨识度的色彩语言：
- 森林: 绿色草地 + 蓝天，温暖明亮，新手安全区
- 沙漠: 金黄沙丘 + 仙人掌，高对比度，开阔感强
- 雪原: 纯白 + 冰蓝，宁静但危机四伏
- 地下洞穴: 深褐 + 矿脉荧光色，幽暗神秘
- 地狱: 暗红 + 橙黄岩浆，压迫感
- 腐化/猩红: 紫与血红，克苏鲁诡异美学
- 空岛/太空: 深紫渐变黑，点缀星空
- 昼夜交替 + 季节事件改变色调（血月暗红天空、日食昏黑、南瓜月橙光）

### 🏗️ 像素建筑美学
- 颗粒感天然「留白」，玩家大脑自动补全细节，激发比高清更强的想象力
- 「像素之外，还有艺术」

## ✅ 应用到「碳衡物语」WorldScene 的落地（2026-08-24 Robin 实现）
1. **像素纹理生成**: `textures.createCanvas` + 像素矩阵/程序化噪点（草块/泥土/石头/角色/树/云/山）
2. **3 群系水平分区**: 森林(0-1600) → 沙漠(1600-3200) → 雪原(3200-4800)，地表色/天空色/植被各自语言
3. **地下层**: 泥土 → 石头，石头随机荧光矿脉点（泰拉瑞亚洞穴味）
4. **昼夜循环**: ~100s 一周，白天→黄昏→夜晚，天空色渐变 + 星空 + 夜晚氛围罩 + 太阳/月亮
5. **像素装饰**: 橡树/仙人掌/雪松（按群系）、飘动云朵、双层视差远山剪影
6. **角色像素化**: 4 角色共用像素模板（12×16 @2），发色/衣色区分，带暗色描边
