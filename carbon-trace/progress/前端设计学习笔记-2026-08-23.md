## 一、SURF surfplus 设计系统（重点参考，海钺指定）

来源：`SURF-platform/github/surfplus-main/surf-campus/frontend/demo.css`

|---|---|---|

### 关键设计亮点

1. **浅色 + 深色双主题**：`data-theme="dark"` + `prefers-color-scheme` 自动切换，深色用 `#121714` 深绿黑底 + 亮绿 `#7bc39a`
2. **3 个缓动函数**（精心的 cubic-bezier）：
   - `--ease-out: cubic-bezier(.23,1,.32,1)`（退出/常态）
   - `--ease-move: cubic-bezier(.77,0,.175,1)`（移动）
   - `--ease-drawer: cubic-bezier(.32,.72,0,1)`（抽屉）
3. **响应式三栏 → 两栏 → 单栏**：
   - 桌面：`224px 主内容 760px 上下文栏`（三栏）
   - 平板 1120px：去掉上下文栏
   - 手机 800px：单栏 + 底部 8 tab 导航（中央浮动 compose 圆钮）
4. **无障碍**：`prefers-reduced-motion` / `reduced-transparency` / `contrast` / `focus-visible`
5. **吉祥物系统**：登录页 4 个角色（紫/黑/黄/橙），mood 驱动的表情动画（眼睛/嘴巴/手臂随状态变化）

核心可借鉴的学术思路：
1. **游戏化促进行为改变**：积分/徽章/等级/连续打卡 → 增强用户长期参与（与碳迹的 4 套积分规则吻合）
2. **抽象数据具象化**：把 kgCO₂ 转化为用户可感知的比喻（如"相当于种 N 棵树"）
3. **反馈即时性**：记碳后立刻给积分/动画反馈，强化行为闭环

## 四、对「碳迹」前端的设计建议

1. **主色从紫色改为绿色**：碳迹是环保主题，参考 surfplus 的 `#176341` 深森林绿更契合（我之前参考旧 surf-campus 用了紫色 #534AB7，建议改回绿色）
2. **加双主题**（浅色 + 深色），参考 surfplus 的 data-theme 方案
3. **引入 3 个缓动函数**，动效更精致
4. **移动端底部导航**已经是 Tab 结构，可参考 surfplus 的中央浮动 compose 按钮（记碳作为核心动作，可以做成中央大按钮）
5. **记碳反馈具象化**：参考 shootismoke，把"减排 X kg" 显示成"相当于种了 Y 棵树"或"少用了 Z 度电"
6. **无障碍**：补 reduced-motion 等
