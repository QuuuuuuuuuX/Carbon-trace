## 四、技术坑记录（重要）

1. **Phaser 4.2.1 移除了 `make.graphics()`**，纹理生成改用 `textures.createCanvas()` + Canvas 2D
2. **.bat 文件需 CRLF 换行 + 纯 ASCII**（Windows cmd 用 GBK 读 UTF-8 会乱码）
3. **FastAPI Annotated 依赖**：`CurrentUser = Annotated[User, Depends(...)]` 需直接 `user: CurrentUser` 且放在有默认值参数前；最稳写法 `user: User = Depends(get_current_user)`
4. **摄像机跟随**：Phaser 4 的 `startFollow` + `setDeadzone` 组合、手动 `scrollX` 赋值均未在浏览器端验证成功（本机无法 headless 截图，需人工验证）
